# ✨ maki-land

> **Interactive Dynamic Island & Floating Desktop Capybara Companion for macOS and Windows 10/11**

Aplikasi Dynamic Island interaktif di tengah atas layar dengan maskot Capybara hidup ("Maki") yang bisa diajak bermain di Desktop, merawat kebutuhan harian, mengelola file & screenshot, serta terintegrasi langsung dengan Google Gemini AI ("Tanya Maki").

---

## 💻 Platform yang Didukung

### 1. 🍎 macOS (Apple Silicon & Intel)
- Codebase asli Swift & SwiftUI di folder root (`Sources/`).
- Dibangun dengan Swift Package Manager (`swift build -c release`).
- Dynamic Island terpasang di bawah Hardware Notch MacBook atau di tengah atas monitor eksternal.

### 2. 🪟 Windows 10 & Windows 11 (64-bit)
- Folder proyek khusus di [`maki-land-windows/`](file:///Users/ari/Documents/antigravity/calm-einstein/maki-land-windows).
- Dibangun dengan Electron, TypeScript, Vite, dan React dengan kesetaraan fitur penuh 100%.
- File portable siap pakai: [`maki-land-Windows-Portable.exe`](file:///Users/ari/Documents/antigravity/calm-einstein/maki-land-windows/release/maki-land-Windows-Portable.exe).
